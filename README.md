# NewGame Modpack Server

We experiment install a non-GUI linux on old used HTC One M8 to run NewGame Modpack Minecraft Server and play online via Tailscale.

## Hardware Specs
HTC One M8
- **CPU**: Qualcomm MSM8974AB Snapdragon 801 (28 nm) Quad-core 2.3 GHz (US/EMEA)/ 2.5 GHz (Asia, China) Krait 400
- **GPU**: Adreno 330
- **RAM**: 2 GB
- **Storage**: 16 GB
